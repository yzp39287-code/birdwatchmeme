隐私与内容说明

邮箱只用于登录投票

普通用户输入的邮箱由 Supabase Authentication 用于发送一次性登录链接、识别投票账户并执行“每天一票”。本站页面不会公开显示登录邮箱，也不会将邮箱用于营销邮件。

统计信息

本站使用 Cloudflare Web Analytics 查看汇总访问量和页面性能，不在本站建立用于广告追踪的个人访客档案。

投稿与来源

管理员可为图片记录作者、投稿者、来源名称和来源链接。转载内容仍归原作者或权利人所有。

侵权或不适内容处理

如需补充署名、修改来源或申请删除，请通过 GitHub 提交说明，并附上对应作品链接及能够说明权利关系的信息。管理员可先隐藏内容，再核实并永久删除。
